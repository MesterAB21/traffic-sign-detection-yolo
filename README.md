# Traffic Sign Object Detection — YOLO

An object detection project developed for a **Traffic Sign Detection Challenge**, using YOLO to detect and localize traffic signs in road images across eight categories.

## Project Overview

The project covers the complete object detection workflow, from dataset preparation and annotation conversion to model fine-tuning, evaluation, and competition submission.

- **Task:** Object detection
- **Model:** YOLO
- **Classes:** 8 traffic sign categories
- **Framework:** PyTorch
- **Dataset:** Traffic Sign Detection Challenge
- **Public Score:** 0.93010

## Workflow

- Converted COCO annotations into YOLO format.
- Prepared training and validation datasets.
- Fine-tuned a YOLO detector for traffic sign localization and classification.
- Evaluated predictions using precision, recall, and mean Average Precision (mAP).
- Generated predictions in the required Kaggle submission format.

## Results

Achieved a **0.93010 public test score** on the competition leaderboard.

## Technologies

- Python
- PyTorch
- YOLO
- OpenCV
- NumPy
- Kaggle

## Objective

Develop an object detection model capable of identifying traffic signs and predicting their locations in real-world road scenes.

## Challenge

The project was developed as part of a Kaggle Traffic Sign Object Detection Challenge.
